# Seguridad Informática I

Aplicación Node.js con Express y PostgreSQL para acceso, registro, confirmación
y recuperación de cuentas.

## Requisitos

- Node.js.
- PostgreSQL.

## Instalación

1. Ejecuta `npm install`.
2. Completa las credenciales de PostgreSQL y correo en `config/config.json`.
3. Crea la base de datos `mesadepartes`.
4. Importa `docs/schema.sql` en PostgreSQL.
5. Inicia la aplicación con `npm start`.
6. Abre `http://localhost:3000/login`.

Las plantillas mantienen el HTML, CSS, imágenes, textos y estructura visual del
proyecto original. La carpeta `assets/` contiene los recursos originales y no
debe modificarse.
